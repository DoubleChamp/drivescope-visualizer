# DriveScope 프로젝트 개요

## 문서 역할

이 문서는 DriveScope가 해결할 문제와 첫 번째 데모, MVP 범위를 정의하는 기준 문서다. 단계별 구현 순서와 현재 진행 상황은 각각 [ROADMAP.md](./ROADMAP.md)와 [PROGRESS.md](./PROGRESS.md)에서 관리한다.

## 제품 목적

DriveScope는 카메라, LiDAR, 객체 인식 결과, 예상 주행 경로를 하나의 타임라인에서 동기화해 자율주행 문제 장면을 분석하는 웹 기반 시각화 도구다.

목표는 특정 사고 위험 장면에서 센서 인식, 객체 인식, Planning 반응, 차량 제어 사이의 시간 관계를 빠르게 파악하는 것이다. Rerun 전체를 복제하거나 새로운 렌더링 엔진을 만드는 것은 목표가 아니다.

현재는 Next.js App Router, TypeScript, Three.js 기반 프로젝트 초기화와 실행 검증을 마쳤다. `/viewer`에 React가 소유하는 Canvas와 Three.js의 Scene, PerspectiveCamera, WebGLRenderer, GridHelper를 만들고 창 크기 변경과 `requestAnimationFrame` 렌더 루프를 연결했다. Phase 2에서는 격자 위의 가상 포인트 100개를 `Float32Array`와 `BufferAttribute`로 직접 연결했다. 가상 데이터로 구조를 학습하고 검증한 뒤 nuScenes mini를 연결한다.

## 핵심 분석 질문

- 카메라는 보행자를 언제 확인했는가?
- LiDAR는 보행자를 언제 감지했는가?
- 객체 인식 결과는 언제 생성됐는가?
- 예상 주행 경로는 언제 보행자와 충돌했는가?
- Planning은 언제 반응했는가?
- 급제동은 적절한 시점에 발생했는가?

## 첫 번째 데모 시나리오

| 시간 | 장면 |
| --- | --- |
| 0~10초 | 차량이 정상 주행한다. |
| 10초 | 보행자가 도로에 등장한다. |
| 11초 | 카메라와 LiDAR 인식 결과에 보행자가 표시된다. |
| 12초 | 예상 주행 경로가 보행자 위치와 충돌한다. |
| 12.4초 | 급제동 이벤트가 발생한다. |
| 이후 | 차량 속도가 감소하고 예상 주행 경로가 변한다. |

이 시나리오는 먼저 가상 데이터로 구현한다. Viewer와 시간 동기화 구조를 완성한 뒤 실제 nuScenes mini 데이터로 교체한다.

## MVP 범위

MVP에 포함한다.

- 전방 카메라 패널 1개
- LiDAR 포인트클라우드
- 차량과 보행자 3D 바운딩 박스
- 예상 주행 경로와 충돌 예상 구간 강조
- 재생, 정지, 타임라인 드래그
- 센서별 타임스탬프 기반 프레임 동기화
- 급제동 이벤트 마커
- 객체 선택과 기본 정보 표시
- FPS, 포인트 수, 프레임 로딩 시간 표시
- 프레임 캐시와 이전·다음 프레임 미리 로딩

## MVP 제외 범위

사용자가 별도로 요청하기 전까지 다음 기능은 구현하지 않는다.

- 카메라 6개와 전체 레이더 데이터
- 복잡한 지도
- 사실적인 자동차 모델과 Blender 모델링
- 고급 조명과 사실적인 재질
- React Three Fiber
- 순수 WebGPU
- Rust 또는 wgpu 렌더러
- Rerun 전체 기능 복제
- 백엔드 서버
- 로그인과 사용자 권한
- 지나친 디자인 작업

## 성공 기준

MVP는 다음 조건을 만족할 때 성공으로 본다.

- 한 타임라인에서 카메라, LiDAR, 객체 인식, 예상 경로, 차량 상태, 이벤트를 함께 탐색할 수 있다.
- 첫 번째 데모의 보행자 등장부터 급제동 이후까지 시간 관계를 재생과 탐색으로 확인할 수 있다.
- 객체를 선택해 기본 정보를 확인하고, 예상 충돌 구간과 급제동 시점을 식별할 수 있다.
- 필요한 프레임만 로딩하고 주변 프레임을 캐시하며, 포인트 Buffer를 재사용한다.
- FPS, 포인트 수, 프레임 로딩 시간을 화면에서 확인해 성능 변화를 수치로 비교할 수 있다.
- React의 UI·입력·재생 상태와 Three.js의 장면·GPU 리소스·렌더 루프 책임이 분리되어 있다.
- 구현 단계마다 사용자가 핵심 원리와 코드의 역할을 설명할 수 있다.
